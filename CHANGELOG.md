# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-02-15

### Added
- GitHub OAuth authentication system for secure user login
- Cosmic Valentine card generator with astrological compatibility readings
- Terminal UI with rich formatting and animations
- Card export to image files
- Authentication setup documentation (AUTH_SETUP.md)
- Support for Python 3.8+

### Features
- Interactive terminal interface for card generation
- Astrological compatibility analysis using Kerykeion
- Image generation with customizable styling
- GitHub OAuth integration with local token persistence
